# Geston-Md-mini — déploiement gratuit sur Koyeb

1. Mets ce dossier dans un dépôt GitHub (public ou privé).
2. Crée un compte Koyeb et choisis **Create Web Service → GitHub**.
3. Sélectionne le dépôt `Geston-Md-mini`.
4. Build command: `npm install`
5. Run command: `npm start`
6. Port: `10000`
7. Ajoute les variables d'environnement:
   - `SESSION` = ta session WhatsApp de Geston-Md-mini
   - `BOTNAME` = `Geston-Md-mini`
   - `CODE` = `243` (optionnel)
8. Déploie.

Important: utilise une **nouvelle session WhatsApp** pour le mini-bot. Ne partage jamais ta SESSION dans un dépôt GitHub.
